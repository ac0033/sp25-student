# Data 100 · Spring 2025

UC Berkeley Data 100（Principles and Techniques of Data Science）的课程材料与个人学习索引。本公开仓库保留讲义、数据、辅助代码和项目目录，**不是一套完整的已解答作业发布包**。

## 内容导航

| 目录 | 内容 |
|---|---|
| [lecture/](lecture/) | 讲义 Notebook 与示例数据 |
| [lab/](lab/) | 实验配套数据、图像与辅助文件，包括 lab02A / lab02B |
| [hw/](hw/) | 作业配套资料，包括 hw02A / hw02B |
| [proj/](proj/) | projA1、projA2、projB1、projB2 项目材料 |
| [disc/](disc/) | 讨论课资料 |
| [grad-proj/](grad-proj/) | 研究生项目相关材料 |
| [期末参考表](sp25_final_reference_sheet.pdf) | Spring 2025 final reference sheet |

当前公开树中的 Notebook 集中在讲义与讨论等目录；`hw/`、`lab/`、`proj/` 中没有 `.ipynb` 作业文件。不要把目录存在或配套数据公开解读为完整答案已经公开。

## 使用

```bash
git clone https://github.com/ac0033/sp25-student.git
cd sp25-student
```

从 `lecture/` 中选择 Notebook 阅读，运行时保持同目录数据路径并按文件中的 import 准备依赖。各目录材料的完整性不同，本仓库不提供统一的作业运行命令。
