## 📖 About This Repository

This repository contains my completed coursework for **UC Berkeley's Data 100 (Spring 2025)** — an upper-division data science course covering the full data science lifecycle: data acquisition, cleaning, exploratory analysis, modeling, and inference.

## 🛠️ Technical Skills Demonstrated

- **Languages & Libraries**: Python, NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn
- **Data Processing**: Data cleaning, feature engineering, ETL pipelines, regular expressions
- **Statistical Modeling**: Linear & logistic regression, regularization (Ridge/Lasso), cross-validation
- **Machine Learning**: Classification, clustering (K-means), dimensionality reduction (PCA)
- **Statistical Inference**: Bootstrap methods, confidence intervals, MLE
- **Databases**: SQL (SELECT, JOINs, subqueries, aggregation)
- **Data Visualization**: Exploratory plots, statistical graphics, design principles
- **NLP Fundamentals**: Text processing, sentiment analysis, large language models
- **Computer Vision**: Image classification, feature extraction (graduate project)
- **Tools**: Jupyter Notebook, Git, VS Code, command-line proficiency
